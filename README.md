# CombinedStatus | 三合一状态栏

**Three-in-One Status Bar for Android**

一个基于 LSPosed 的 Android 状态栏增强模块，将电池、Wi-Fi 和移动网络信号整合到一个简洁、可自定义的图标中。

An Android status bar enhancement module based on LSPosed, combining battery, Wi-Fi and mobile network indicators into one compact and customizable icon.

---

## ✨ Features | 功能介绍

- **三合一显示 / Combined Indicator**  
  将电池、Wi-Fi 和移动网络信号整合到一个状态栏图标中。  
  Combine battery, Wi-Fi and cellular signal indicators into one icon.

- **多种样式 / Multiple Styles**  
  支持多种三合一图标风格，包括胶囊样式及其他自定义布局。  
  Multiple visual styles, including capsule layouts and other customizable designs.

- **双卡支持 / Dual SIM Support**  
  支持双 SIM 卡信号显示。  
  Supports dual-SIM signal indicators.

- **外观自定义 / Appearance Customization**  
  支持调整图标大小、粗细、颜色、布局及排列方式。  
  Customize icon size, thickness, color, layout and arrangement.

- **充电状态 / Charging Indicator**  
  支持根据充电状态调整图标显示。  
  Supports charging-state visual indicators.

- **多场景适配 / Multi-Scenario Support**  
  针对状态栏、锁屏及下拉面板等场景进行适配。  
  Adaptations for the status bar, lock screen and notification shade.

- **实时预览 / Live Preview**  
  提供样式预览及场景模拟功能。  
  Includes style previews and scenario simulation.

## 🚀 Installation | 安装方法

1. 确保设备已安装并正常运行 LSPosed。
2. 从本项目的 GitHub Releases 下载最新 APK。
3. 安装 APK。
4. 打开 LSPosed Manager，启用 CombinedStatus 模块。
5. 按模块要求选择相应作用域。
6. 根据提示重启 System UI 或设备。
7. 打开 CombinedStatus，配置所需的图标样式。

### Updating | 更新方法

1. 下载 GitHub Releases 中的最新 APK。
2. 直接覆盖安装现有版本。
3. 确认 LSPosed 中模块仍然启用。

**注意：** 新版本必须使用相同的 Application ID 和签名证书，才能正常覆盖安装。
